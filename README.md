# AlgoForge

AlgoForge is a coding practice platform focused on solving algorithm and data structure problems through a dedicated frontend and backend setup.

> Status: This project is still in making and is being actively built. Features, structure, and documentation may continue to change.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Node.js
- Express
- MongoDB
- BullMQ
- Docker

## Project Structure

- `Frontend/` contains the React application.
- `Backend/` contains the API, authentication, problem routes, queue workers, and code execution flow.

## Features Planned / In Progress

- Problem exploration by topic
- Practice dashboard
- Code editor and execution flow
- User profile support
- Submission handling
- Authentication

## Run Locally

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
npm run dev
```

The backend expects local services like MongoDB and environment variables for authentication to be configured.
