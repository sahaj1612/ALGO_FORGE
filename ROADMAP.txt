New Architecture:

Client
   ↓
API Server
   ↓
MongoDB (store submission)
   ↓
Redis Queue (BullMQ)
   ↓
Worker Service
   ↓
Docker Sandbox
   ↓
Judge Engine
   ↓
Result Saved
   ↓
Frontend polls result

Tasks:

• Create Submission Model
• Status = QUEUED / RUNNING / ACCEPTED / WA / TLE / RE
• Push submission job to queue
• Worker picks job
• Run docker for EACH testcase
• Compare output
• Generate verdict
• Save runtime + memory
