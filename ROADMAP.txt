CODE EXECUTION ENGINE FLOW

User submits code → API stores submission → pushed to Redis queue → worker picks job → code runs inside Docker sandbox → output compared → result saved


---

DETAILED FLOWS

AUTHENTICATION FLOW User → Login → API validates → generate tokens → store session → authenticated
If expired → Refresh API → new access token

FETCH PROBLEM FLOW Frontend requests → check Redis → if not → MongoDB → cache → return

SUBMISSION FLOW User submits → store QUEUED → push to queue → return "Running"

WORKER FLOW Worker pulls job → compile → run test cases → compare output → store result

RESULT FLOW Worker updates status → invalidate cache → update leaderboard

USER RESULT FLOW Frontend polls /submission/:id → latest verdict

LEADERBOARD FLOW Accepted → update score → Redis ranking → DB persistence
